# 常见报错与处理

## 一、Windows：命令提示「不是内部或外部命令」

**现象：** 在命令行里输入某个命令（例如查看版本号）后提示「不是内部或外部命令，也不是可运行的程序」。

**原因：** 软件没有装好，或者安装后系统环境变量还没有刷新。

**处理：**

1. 先关闭命令行窗口，**重启电脑**，再重新试一次；
2. 仍然不行，回到安装步骤，重新下载官方安装包安装；
3. 安装时留意是否有「添加到 PATH / 环境变量」之类的选项，勾选后再装一次。

## 二、网络工具不稳定

**现象：** 经常断线，或者网页时而能打开时而不能。

**处理：** 更换口碑稳定的付费服务，不要用免费服务；长期固定使用一个地区的节点。

## 三、Mac：提示「未打开某 App，Apple 无法验证…」

**现象：** 打开从浏览器、网盘、聊天软件或压缩包、磁盘映像（DMG）里得到的第三方应用时，弹出：

```text
未打开“某某应用”
Apple 无法验证“某某应用”是否包含可能危害 Mac 安全或泄漏隐私的恶意软件。
```

按钮通常有：完成、移到废纸篓。

**原因：** 这是 macOS 的安全机制（Gatekeeper）在拦截。常见原因是该应用没有经过 Apple 的开发者签名与公证，或者下载后带有「隔离标记」。它通常不是账号问题、也不是软件逻辑错误。

**处理步骤（按顺序试）：**

先点「**完成**」，不要点「移到废纸篓」。

方法 1：用右键打开

1. 打开访达，找到这个应用；
2. 如果还在磁盘映像里，先把应用拖到「应用程序」文件夹；
3. 按住 **Control** 键，点击这个应用；
4. 选择「打开」；
5. 再次弹出提示时，继续点「打开」。

方法 2：在系统设置里允许

1. 点屏幕左上角的苹果菜单 → 系统设置；
2. 进入「隐私与安全性」；
3. 向下找到刚才被拦截的应用；
4. 点「仍要打开」；
5. 输入电脑密码确认。

方法 3：命令行清除隔离标记（前两种都不行时再用）

```bash
xattr -dr com.apple.quarantine "/Applications/应用名.app"
open "/Applications/应用名.app"
```

把「应用名」换成实际名称。不知道应用位置时，可以在终端里先输入 `xattr -dr com.apple.quarantine ` 再把应用图标拖进终端窗口，自动补全路径。

**安全边界（重要）：**

只有在以下条件都满足时，才应绕过拦截：

1. 软件来源明确，例如来自你信任的人给的链接；
2. 软件名称与你预期的一致；
3. 不是在搜索引擎里随便搜到同名软件下载的；
4. 下载后没有被改名或二次打包过。

来源不明的软件，不要执行清除隔离标记的命令。

**VPN 类应用的额外提醒：** 第一次打开后，系统可能还会继续弹出权限请求，例如「是否允许添加 VPN 配置」「是否允许网络扩展」，都需要选择允许；如果没有弹窗，到「系统设置」里的 VPN 或「隐私与安全性」手动允许。不允许的话，应用能打开但连不上。

**给他人排查时的顺序：**

1. 软件是否来自你提供的链接？
2. 对方点的是「完成」还是「移到废纸篓」？
3. 应用是否已经拖进「应用程序」文件夹？
4. 是否试过 Control 点击打开？
5. 「系统设置 → 隐私与安全性」里有没有「仍要打开」？
6. 如果是 VPN 类应用，是否允许了 VPN 配置？

**预防（给分发软件的人）：** 在说明里提前写明「第一次打开可能被苹果拦截，这是正常的安全提示」；条件允许时给应用做签名和公证；提前准备好「允许打开」的截图说明。
