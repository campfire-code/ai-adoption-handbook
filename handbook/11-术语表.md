# 术语表

| 术语 | 含义 |
|---|---|
| Agent（智能体） | 能按你的描述自动执行一连串操作的 AI 助手，例如替你下载、安装软件、修改文件 |
| 命令行（CLI） | 用文字命令操作电脑的窗口，例如 Windows 的 cmd |
| 桌面版 | 带图形界面的应用，通常带沙箱，权限受限 |
| 沙箱 | 受限制的运行环境，程序不能随意访问电脑的其他部分 |
| 版本管理 | 给项目的每次修改存档，可随时回退，GitHub 是常见服务 |
| 令牌（Token） | 一串用来代替密码的访问凭证，只显示一次，需妥善保管 |
| PRD | 需求文档，写明做什么、怎么做、技术选型与部署方式 |
| 氛围编程 | 向 AI 提供尽可能丰富的背景信息，而不只是下命令 |
| Gatekeeper | macOS 对未签名或未公证应用的安全拦截机制 |
| 隔离标记 | 从网络下载的文件被系统加上的标记，会触发安全检查 |
| 备案 | 在国内使用域名对外提供网站服务所需完成的登记 |
| 灾备 | 出现故障时能够恢复业务的备份与恢复安排 |
