# 在 Windows 上安装第一个 AI 助手

> 本章以一款名为 Codex 的命令行 / 桌面 AI 助手为例说明流程。下载入口、安装包类型和界面以官方页面为准。

## 它是什么

Codex 是一类「智能体（Agent）」型的 AI 助手：你用日常语言描述任务，它可以在电脑上替你执行操作，包括帮你下载、安装其他软件。

先装它的原因有两个：

- 它能帮你装后面的工具，省去自己逐个折腾；
- 它可以作为主力工具之外的第二条路，用于兜底（见第 8 章）。

## 安装步骤

1. 在浏览器里搜索「Codex download」之类的关键词，找到**官方页面**。官方页面的判断方法：域名属于服务商本身，或者是该产品公开的代码托管主页。不要从搜索结果里的第三方下载站下载。
2. 选择 Windows 版本，下载安装包。
3. 双击安装包，按提示逐步点「下一步」直至完成。

## 验证安装

1. 同时按下键盘上的 **Windows 键 + R**，弹出「运行」窗口；
2. 输入 `cmd`，点击确定，打开黑色的命令行窗口；
3. 输入下面这行命令并回车：

```
codex --version
```

- 显示出一串版本号：安装成功。
- 显示「不是内部或外部命令」：说明没有装好或系统还没有刷新环境变量，**先重启电脑再试一次**；仍然不行，再回到安装步骤重装。

## 注册账号与开通套餐

1. 用准备好的邮箱，在官网完成注册（手机号验证时按页面提示选择区号）。
2. 开通付费套餐。套餐名称、价格、可用额度**以官网为准**。
3. 开通后重新登录，页面上应显示你当前的套餐标识。

## 这一步的验收标准

- [ ] `codex --version` 能显示版本号
- [ ] 账号能正常登录
- [ ] 页面能看到你的套餐状态
