# 让 AI 助手帮你装工具，并加上版本管理

## 一、让第一个助手替你安装其他工具

### 打开必要的权限

Codex 这类助手默认对电脑的操作权限有限。要让它真的替你下载和安装，需要在它的设置里打开「完全访问（Full Access）」之类的选项。具体名称以软件当前界面为准。

**提示：** 完全访问意味着它可以在你的电脑上执行更多操作。建议只在自己的、没有存放重要机密文件的电脑上开启，并在它执行关键步骤时留意它在做什么。这条是本手册的整理者提示，不是来源原文。

### 直接用中文下达任务

打开后，在对话框里直接说你想要什么，例如：

```
请帮我安装 Claude Code（一个用来写软件的 AI 工具），我用的是 Windows。
```

助手通常会：搜索官方下载地址 → 下载 → 运行安装 → 告诉你安装完成。装完后，用和上一章类似的方法在命令行里验证版本。

> 来源经验：让助手到官方来源去安装，比从来路不明的渠道拿到的安装包更可靠。如果以前是别人帮你装的、你拿不准是否为官方版本，可以卸载后让助手重装。

## 二、给主力工具注册账号

主力工具（用于写代码的 AI 工具）装好后，需要注册它的账号。详细的风险和习惯见第 8 章，这里只列出与步骤相关的要点：

- 使用准备好的邮箱；
- 注册后先少量、稳定地使用一段时间，再决定是否升级套餐；
- 不要在多台、多个地区的设备上同时登录同一个账号。

## 三、版本管理：防止 AI 把项目改乱

### 痛点

让 AI 修改代码，很容易出现「改着改着乱了」：做了第二步忘了第一步，或者改坏了却回不去。

### 解决办法

用 **GitHub** 这类版本管理服务给项目做「存档」：

- 每次 AI 改完，都保存成一个版本；
- 发现这一版不如上一版，可以回退到之前的任意一个版本；
- 多人协作时，一个人做完发布版本，另一个人接着往下做；
- 换成别的 AI 工具，也能在同一份项目上继续做。

### 怎么做

**第 1 步：注册账号。** 在 GitHub 官网注册，按提示验证邮箱。

**第 2 步：生成访问令牌（Token）。** 大致路径是：右上角头像 → 设置 → 开发者设置（Developer settings）→ 个人访问令牌（Personal access tokens）→ 生成新令牌。具体菜单名称以官网当前界面为准。

注意：

- 令牌生成后**只显示一次**，关闭页面就看不到了，必须当场复制并保存在安全的地方；
- 来源材料的做法是权限全部勾选；权限越大风险越大，**整理者建议只勾选实际需要的权限**，并设置有效期；
- 令牌等同于密码，不要发给别人，不要写进文档或聊天记录里。

**第 3 步：交给 AI 工具配置。** 在主力工具里用中文说明你的 GitHub 用户名，并提供令牌，请它配置版本管理。之后它每次完成修改，都会替你把代码同步到 GitHub，你不需要自己操作 GitHub。

### 验收标准

- [ ] GitHub 上能看到项目仓库
- [ ] AI 完成一次修改后，仓库里多出一条新的版本记录
- [ ] 你能让 AI「回退到上一个版本」并看到项目恢复
