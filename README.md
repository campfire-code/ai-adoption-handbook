# AI 落地方法论手册

> AI 工具安装、上手与落地方法论资料包（已脱敏）。篝火出品，版本 0.1.0。

从「装好第一个 AI 助手」到「把 AI 用进业务」的一套中文方法论：环境与账号准备、Windows 安装、让 AI 帮你装工具、版本管理、语音输入、AI 的能力边界、企业落地、账号风险与兜底、常见报错（含 Mac 提示「Apple 无法验证」的处理）。

## 怎么读

- 在线读：按下面的目录点开 `handbook/` 里的章节。
- 离线读 / 打印：仓库里的 `AI 落地方法论手册.pdf` 是全部章节合并后的版本。
- 建议第一次按顺序读，每章末尾有验收标准或核对清单。

## 重要说明

- **以官方为准**：软件界面、价格、套餐、平台政策都会变化。凡涉及这些内容，一律以各官方网站当前页面为准；手册中的步骤用于建立整体印象。
- **经验不是规则**：手册里关于账号、网络、支付的做法是使用经验，不是服务商公布的规则，也不保证有效。请遵守所在地法律法规和各服务商的使用条款。
- **已脱敏**：只保留通用方法，不含任何个人、客户信息和原始录音内容。
